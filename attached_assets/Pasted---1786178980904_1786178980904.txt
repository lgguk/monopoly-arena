Тема: Полная переработка главной страницы — новый макет, кнопки «Создать комнату» / «Найти игру», список лобби с фильтром, чат и боковая панель.

Исходная ситуация: Сейчас на главной странице есть простые кнопки «Начать партию» и «Найти комнату», список комнат неструктурирован, нет фильтров и чата.

Что нужно сделать (изменить только главную страницу, остальные разделы — без изменений):

1. Макет главной страницы (по скриншоту)
Раздели главную страницу на две колонки:

Левая колонка (30% ширины):

Блок «Город сегодня ТВОЙ» с лозунгом и двумя кнопками (см. пункт 2).

Блок «Комнаты» — здесь будет список лобби (см. пункт 4).

Блок «Друзья» — строка поиска по имени или ID (пока просто поле ввода, функционал поиска оставляем как есть).

Блок «Последние события» — лента уведомлений (приглашения в комнаты и т.п.) в виде коротких записей (как на скриншоте).

Правая колонка (70% ширины):

Блок «Список комнат» — таблица/список всех доступных лобби с полной информацией (см. пункт 4).

Внизу страницы (во всю ширину):

Блок «Чат лобби» — общий чат для всех пользователей сайта (см. пункт 5).

2. Кнопки «Создать комнату» и «Найти игру»
Замени старые кнопки на две новые с изменённым функционалом:

Кнопка «Создать комнату» (ранее «Начать партию»):

При нажатии открывается модальное окно с настройками:

Название комнаты (текстовое поле, по умолчанию «Комната [никнейм]»).

Режим игры (выпадающий список): «Классический», «2×2», «3×3».

Количество игроков (слайдер или выбор: 2–6, для командных режимов фиксировано: 4 или 6).

Бонусы стола (чекбоксы):

✅ «Джекпот» (включён по умолчанию)

✅ «Телепорт» (третий кубик, включён по умолчанию)

⬜ «Без аренды» (экспериментальный режим)

Пароль (опционально, если заполнен — комната защищена).

После создания — комната появляется в общем списке, создатель становится её хозяином.

Кнопка «Найти игру» (ранее «Найти комнату»):

При нажатии открывается модальное окно быстрого поиска:

Выбор режима: «Классический», «2×2», «3×3» (радиокнопки или выпадающий список).

Кнопка «Искать» — система находит первую доступную комнату с подходящим режимом и автоматически присоединяет игрока к ней.

Если комнат нет — показывает сообщение «Свободных комнат нет. Создайте свою!» и предлагает перейти к созданию.

3. Блок «Список комнат» (правая колонка, 70%)
Это главный список всех открытых лобби. Должен содержать:

Строка фильтров (над списком):

Выпадающий список «Режим» (Все / Классический / 2×2 / 3×3).

Поле поиска «Поиск по нику или ID комнаты» (текстовый ввод, фильтрует список в реальном времени).

Список комнат (каждая комната — отдельная строка/карточка):

Название комнаты (например, «Только свои»).

Уникальный ID комнаты (например, #A7F3D).

Количество игроков (например, 4/6) — дробь: текущее / максимум.

Режим (Классический / 2×2 / 3×3).

Доп. функции стола (иконки или метки: «🎰 Джекпот», «🌀 Телепорт», «🔒 Пароль»).

Кнопка «Присоединиться» — если место есть и пароль введён (если комната с паролем — запросить пароль в отдельном диалоге).

4. Блок «Чат лобби» (внизу, во всю ширину)
Это общий чат для всех пользователей, находящихся на главной странице (не в игре).

Поле ввода сообщения внизу, кнопка «Отправить».

Сообщения отображаются в виде ленты (как на скриншоте), с указанием никнейма отправителя.

Чат должен обновляться автоматически (для локальной версии — достаточно обновления при отправке, но если будете делать WebSocket — чат живой).

5. Боковая панель (левая колонка, 30%)
Блок «Город сегодня ТВОЙ»:

Слоган, как на скриншоте.

Две кнопки: «Создать комнату» и «Найти игру» (описаны выше).

Блок «Комнаты» — дублирует список комнат? Нет, здесь просто заголовок и возможно краткая статистика (сколько всего комнат открыто).

Блок «Друзья»:

Поле «Поиск по имени или ID» (текстовый ввод).

Список друзей (если есть) с индикатором онлайна (зелёный/серый кружок).

Блок «Последние события»:

Лента из 3–5 последних действий (например, «Макс Волков отправил приглашение», «Комната #A7F3D создана»).

6. Технические требования
Использовать существующие данные (LocalStorage) — все комнаты и пользователи хранятся там же.

При создании комнаты — сохранять её в общий список с параметрами.

При поиске / фильтрации — обновлять список комнат без перезагрузки страницы.

Чат: сообщения хранить в LocalStorage под ключом global_chat_messages (массив объектов: {nickname, text, timestamp}).

Все модальные окна (создание комнаты, поиск игры) должны быть поверх основного контента.

7. Важно!
Не трогать игровой процесс, админ-панель, инвентарь, магазин и рынок — они остаются как есть и доступны через меню.

Главная страница теперь — это основной хаб, вся навигация начинается отсюда.

Сохранить тёмную/нейтральную цветовую гамму (можно доработать позже).

Проверка:

Открой главную страницу — увидишь две колонки и чат внизу.

Нажми «Создать комнату» — откроется модалка с настройками. После создания — комната появляется в списке справа.

Нажми «Найти игру» — найдётся подходящая комната или будет сообщение.

Введи текст в чат — сообщение появится в ленте.

Используй фильтр или поиск — список комнат обновляется.
