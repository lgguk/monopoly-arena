Создай полноценное веб-приложение – игровую платформу «Монополия» с социальными функциями и панелью администратора. Все данные хранятся в LocalStorage (пока без бэкенда). Требования:

1. Авторизация и профили

Вход по уникальному никнейму (без пароля).

Каждому пользователю присваивается уникальный ID.

Профиль: уровень, звания, рейтинг, статистика, кошелёк с валютой «Coins».

2. Лобби и социальная сеть

Создание/поиск комнат с режимами (Классический, 2×2, 3×3), выбором количества игроков, паролем.

Друзья: поиск по ID или никнейму, добавление, список онлайна.

Внутриигровой чат с выбором адресата (всем или конкретному игроку).

3. Сама игра «Монополия»

Поле 40 клеток, стартовый капитал 15 000 Монополек (цены умножены на 10).

Спецполя: Джекпот (накопленные штрафы), Испытание (чёт/нечет).

Третий кубик (случайно 15%) с эффектами: +3 шага, Телепорт на 5 вперёд, +2000 монет, Перемешать игроков, Скидка 30%, Пусто.

Классические правила аренды, строительства (до 5 домов = отель), банкротства.

После игры – начисление опыта и Coins, вероятность выпадения предмета (лутбокса).

4. Магазин (заглушка)

Разделы: «Кейсы» и «Скины» (для кубиков, фишек, поля). Покупка за Coins.

5. Панель администратора (отдельный вход по логину admin и паролю, заданному по умолчанию admin123).

Управление дизайнами полей (добавление/назначение клеткам).

Управление скинами кубиков и фишек (добавление, активация).

Управление кейсами (создание с указанием предметов и вероятностей).

Настройка баланса (стартовый капитал, проход Старта, проценты аренды, шанс Третьего кубика и т.д.).

Просмотр и блокировка пользователей.

Интерфейс должен быть современным, адаптивным, на одной странице (SPA) с переключением вкладок. Реализуй как локальное приложение (hot-seat для игры), но с полноценным видом онлайн-платформы. Если возможно, добавь базовый Node.js сервер для сохранения данных (но это опционально). Основной стек: HTML, CSS, JavaScript (можно использовать React/Vue для удобства, но главное – работающий продукт).

Учти, что админка должна быть защищена паролем, а все изменения сохраняются в LocalStorage. Для изображений используй base64 или ссылки. После создания кода дай инструкцию по запуску.
